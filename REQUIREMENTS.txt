  FEATURES LEFT TO BUILD
----------------------------------------------------------------

  FEATURE 1 — Live Workout Input & Motion Tracking
  -------------------------------------------------
  [ ] Camera access via getUserMedia()
  [ ] Load MediaPipe Pose Landmarker model (WASM)
  [ ] Draw pose skeleton overlay on <canvas>
  [ ] Apply One Euro Filter to all 33 landmark coordinates
  [ ] Output clean landmark stream at ~30fps
  [ ] Handle: no camera permission, loading state, mobile/desktop

  FEATURE 2 — Exercise Form & Rep Analysis
  -----------------------------------------
  [ ] Joint angle calculator (vector trigonometry)
        formula: arccos( dot(v1,v2) / (|v1| * |v2|) )
        joints needed: shoulder, elbow, hip, knee, ankle
  [ ] Form scorer via Cosine Similarity
        compare user angle sequence vs. reference sequence
        output: accuracy % (0–100)
  [ ] Rep detector
        detect UP/DOWN phase transitions on joint angle curve
        increment rep count on full cycle completion
  [ ] Form feedback system
        threshold-based alerts (e.g. knee angle < 60 = too deep)
        visual highlight on skeleton + optional audio beep

  FEATURE 3 — Live Set & Rest Management
  ----------------------------------------
  [ ] Live Set HUD component showing:
        - Reps completed / target reps
        - Current set / total sets
        - Exercise velocity (landmark delta / time)
        - Time under tension (TUT) timer
        - Effort level / RPE (1–10, from velocity ratio)
  [ ] "Set Complete" detection (user stops moving / manual tap)
  [ ] Dynamic rest timer countdown after set
  [ ] Rest tips display (random tip from tip library)
  [ ] "Next set in X sec" alert

  FEATURE 4 — Adaptive Fatigue Analysis
  ---------------------------------------
  [ ] Track rep velocity for each rep in a set (array)
  [ ] Baseline = average velocity of first 3 reps
  [ ] Fatigue detected if current velocity < baseline * 0.80
  [ ] Fatigue levels: Normal → Warning → Fatigue Detected
  [ ] Recommendation engine:
        Normal      → "Keep going"
        Warning     → "Slow down, focus on form"
        Fatigue     → "Consider ending the set"
  [ ] Pass fatigue data to analytics + muscle heatmap

  FEATURE 6 — Analytics & Progress Monitoring
  ---------------------------------------------
  [ ] Muscle fatigue & recovery heatmap
        body diagram colored by fatigue level per muscle
        recovery estimate (e.g. 48h after high fatigue)
  [ ] Workout volume graph (line/area chart)
        X-axis: dates, Y-axis: total volume (sets×reps×weight)
  [ ] 1RM Estimation progress chart
        Epley formula: 1RM = weight * (1 + reps / 30)
        track 1RM per exercise over time
  [ ] Consistency tracking
        already built in Feature 5 (streak + heatmap)
        wire up to show real session data
